# Farosatxona infratuzilmasi

`railway.ts` rasmiy `railway/iac` SDK bilan Farosatxona servisi va uning doimiy diskini ta’riflaydi.

Tartib: `railway config plan`, tekshirish, `railway config apply`. Kod GitHub’dagi `brolaziz/farosatxona` repozitoriyning `main` tarmog‘idan olinadi.

Maxfiy qiymatlar `preserve()` bilan serverda saqlanadi. Repozitoriyga token yozmang.

`partial = "farosatxona"` bir loyihadagi boshqa repozitoriylar servislarini ushbu fayldan boshqarishni cheklaydi. Mavjud servis nomi boshqacha bo‘lsa, avval konfiguratsiya va resurs bog‘lanishini moslang. Plan o‘chirishlarni ko‘rsatsa sababini aniqlamay davom etmang.

To‘liq qo‘llanma: [Railway](../docs/railway.md).
